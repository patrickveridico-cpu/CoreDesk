# Atalhos de Operações

Os comandos são registrados pelo `CommandRegistry`. A navegação interna pode ser aberta por `operations.open-*`; ações de cálculo e cópia permanecem disponíveis pelo fluxo da página. Atalhos adicionais só devem ser incluídos após verificar conflitos com Ctrl+1–9, Ctrl+Tab e comandos do navegador.
